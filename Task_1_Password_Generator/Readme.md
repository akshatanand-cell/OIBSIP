# 🔐 Password Generator
### Akshat Anand | Oasis Infobyte Python Internship

## 📌 Project Overview
An advanced GUI-based Random Password Generator built with Python and Tkinter.

## ✨ Features
- Adjustable password length (6–64 characters)
- Toggle Uppercase, Lowercase, Digits, Symbols
- Exclude specific characters
- Generate multiple passwords at once
- Real-time password strength meter
- One-click copy to clipboard
- Password history viewer

## 🛠️ Tech Stack
- Python 3.x
- Tkinter (GUI)
- pyperclip (Clipboard)

## ▶️ How to Run
pip install pyperclip
python password_generator.py
