# ⚖️ BMI Calculator
### Akshat Anand | Oasis Infobyte Python Internship

## 📌 Project Overview
An advanced GUI-based BMI Calculator built with Python and Tkinter.
Supports multiple users, data storage, and BMI trend visualization.

## ✨ Features
- Metric and Imperial unit support
- BMI calculation with health category
- Personalized health advice
- Data storage for multiple users (JSON)
- BMI history trend graph (Matplotlib)
- View all users and their records
- Clean dark-themed UI

## 🛠️ Tech Stack
- Python 3.x
- Tkinter (GUI)
- Matplotlib (Graphs)
- JSON (Data Storage)

## ▶️ How to Run
pip install matplotlib
python bmi_calculator.py
