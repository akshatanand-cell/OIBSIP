## ✨ Features

| Feature | Description |
|--------|-------------|
| 📏 **Dual Units** | Supports both Metric (kg/m) and Imperial (lbs/ft) |
| 🧮 **BMI Calculation** | Accurate BMI formula with instant results |
| 🏷️ **Health Category** | Classifies into Underweight, Normal, Overweight, Obese |
| 💡 **Health Advice** | Personalized tip based on your BMI result |
| 👥 **Multi-User** | Store and track data for multiple users |
| 📈 **Trend Graph** | Visualize your BMI history with Matplotlib |
| 🗂️ **All Records** | View every user's complete BMI history |
| 💾 **Data Storage** | Saves all records locally in JSON format |
| 🌙 **Dark Theme** | Modern dark-themed UI |

## 🚀 Getting Started

### Prerequisites
```bash
python --version  # Python 3.x required
```

### Installation

**1. Clone the repository**
```bash
git clone https://github.com/akshatanand-cell/OIBSIP.git
cd OIBSIP/Task_2_BMI_Calculator
```

**2. Install dependencies**
```bash
pip install matplotlib
```

**3. Run the app**
```bash
python bmi_calculator.py
```
