# 🎙️ Voice Assistant — Nova
### Akshat Anand | Oasis Infobyte Python Internship

## 📌 Project Overview
An advanced GUI-based Voice Assistant built with Python and Tkinter.
Nova can respond to voice commands and typed input.

## ✨ Features
- Voice input via microphone
- Text-to-speech responses
- Tell current time & date
- Tell jokes
- Google web search
- Open YouTube, GitHub, LinkedIn
- Open Calculator
- Chat-style interface with timestamps
- Quick command buttons
- Dark-themed UI

## 🛠️ Tech Stack
- Python 3.x
- Tkinter (GUI)
- SpeechRecognition
- pyttsx3 (Text to Speech)
- PyAudio

## ▶️ How to Run
pip install speechrecognition pyttsx3 pyaudio
python voice_assistant.py
