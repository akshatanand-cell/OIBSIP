## 🚀 Getting Started

### Prerequisites
Make sure you have **Python 3.x** installed.
```bash
python --version
```

### Installation

**1. Clone the repository**
```bash
git clone https://github.com/akshatanand-cell/OIBSIP.git
cd OIBSIP/Task_4_Voice_Assistant
```

**2. Install dependencies**
```bash
pip install speechrecognition pyttsx3 pyaudio
```

**3. Run the app**
```bash
python voice_assistant.py
```

## 🗣️ What Can Nova Do?

Try saying or typing these commands:

```
"Hello"                    → Get a greeting based on time of day
"What time is it?"         → Hear the current time
"What's today's date?"     → Get today's full date
"Tell me a joke"           → Hear a random joke
"Search Python tutorials"  → Opens Google search
"Open YouTube"             → Opens YouTube
"Play lo-fi music"         → Searches YouTube
"Open GitHub"              → Opens your GitHub profile
"Open calculator"          → Launches system calculator
"What can you do?"         → See all commands
"Goodbye"                  → Exit greeting
```
